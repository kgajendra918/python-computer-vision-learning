# 🖼️ Image Processing using Python

## 📌 About the Project
This repository contains my hands-on practice and learning in **Image Processing using Python** as part of my technical training at **Innomatics Research Labs**.

The project explores fundamental image processing techniques using Python libraries, helping me understand how digital images can be read, manipulated, and transformed.

## 🛠️ Technologies Used
- Python
- OpenCV (cv2)
- NumPy
- Matplotlib
- Jupyter Notebook

## 📚 Topics Covered
- Reading and displaying images
- Understanding image arrays and dimensions
- Image resizing and compression
- Color space conversion (RGB, BGR, Grayscale, HLS)
- Image cropping using pixel slicing
- Creating black and white images
- Adding text to images

## 💻 Tools & Environment
- Jupyter Notebook
- Anaconda
- Python 3

## 🎯 Learning Outcome
Through this practical implementation, I gained hands-on experience in basic image manipulation and developed a foundation for exploring Computer Vision and advanced image processing techniques.
