# 🚀 Python & Computer Vision – Hands-on Learning

Welcome to my practical learning repository! This repository showcases my hands-on practice and exploration of **Python, OpenCV, Computer Vision, and AI-based applications** as part of my technical training at **Innomatics Research Labs**.

Through these notebooks, I am building practical knowledge by implementing different image processing, video processing, and computer vision techniques.

## 📂 Repository Contents

### 1. 🖼️ Image Pre-processing
**File:** `image pre-processing(1).ipynb`

Exploring fundamental image processing techniques using Python.

Topics covered:
- Reading and displaying images
- Image resizing and cropping
- RGB, Grayscale, HLS, and HSV conversions
- Creating black and white images
- Drawing shapes and adding text
- Image stacking using NumPy

### 2. 🎥 Accessing the Video
**File:** `Accessing The Video.ipynb`

Learning video processing techniques using OpenCV.

Topics covered:
- Reading video files
- Extracting and displaying video frames
- Accessing webcam
- Real-time frame processing
- Drawing rectangles and adding text to video frames

### 3. 🎯 Object Detection using YOLO
**File:** `Detecting Objecys.ipynb`

Exploring real-time object detection using the YOLO model and OpenCV.

Topics covered:
- YOLO model implementation
- Real-time webcam object detection
- Confidence threshold configuration
- Class-specific object detection
- Visualizing detection results

### 4. 🚗 AI-Powered Driver Drowsiness Prediction System
**File:** `AI-Powered Driver Drowsiness Prediction System.ipynb`

Exploring an AI-based driver safety application using computer vision and facial landmarks.

Topics covered:
- Understanding driver drowsiness detection
- MediaPipe Face Landmarker
- Facial landmark detection
- Eye Aspect Ratio (EAR)
- Mouth Aspect Ratio (MAR)
- Real-time webcam processing
